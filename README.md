One original one-line joke about office life, written by a small deterministic
TypeScript program. The program holds the line, checks it against the bounty
gate (UTF-8 text, 1 to 200 characters, a single line, not only white space),
and writes it to `/output/entry.txt`. Every run produces byte-identical output.

## Run it

```sh
node main.ts
```
